# Rắn Săn Mồi

Trò chơi Snake nhỏ gọn chạy hoàn toàn trên trình duyệt và được thiết kế để triển khai trực tiếp bằng GitHub Pages.

## Điều khiển

- Phím mũi tên hoặc `WASD`: đổi hướng
- `Space`: tạm dừng / tiếp tục
- Trên điện thoại: dùng các nút điều hướng trên màn hình

Mở `index.html` để chơi trên máy hoặc bật GitHub Pages cho nhánh `main` để xuất bản.
